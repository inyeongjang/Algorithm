### 핵심 로직

1. 정답을 저장할 `answer` 배열을 0으로 초기화 

2. 아직 가격이 떨어지지 않은 인덱스를 `stack`에 저장

3. 가격을 왼쪽부터 하나씩 확인

4. 현재 가격이 스택의 마지막 가격보다 낮으면, 해당 인덱스를 스택에서 꺼내고, `현재 인덱스 - 꺼낸 인덱스`를 정답으로 저장

5. 남은 스택 인덱스에 대해서도 같은 과정을 반복

6. 현재 인덱스를 스택에 저장 

7. 모든 가격을 확인한 뒤 스택에 남은 인덱스들은 `마지막 인덱스 - 해당 인덱스`를 정답으로 저장

### 복잡도

- 시간 복잡도: O(n)

  각 인덱스는 스택에 한 번 들어가고 한 번만 빠져나오므로 전체 연산 횟수는 최대 약 2n

- 공간 복잡도: O(n)

  answer와 stack이 최대 n개의 값을 저장
