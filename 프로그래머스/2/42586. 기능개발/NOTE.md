### 핵심 로직
1. 각 기능이 완료되기까지 필요한 날짜를 계산해 `days`에 저장한다.
2. 첫 번째 기능의 완료일을 현재 배포 기준일인 `current`로 설정한다.
3. 완료일이 `current` 이하이면 앞 기능과 함께 배포하므로 `count`를 증가시킨다.
   
   완료일이 `current`보다 크면 기존 그룹의 개수를 `answer`에 저장하고, 해당 기능부터 새로운 배포 그룹을 시작한다.
4. 반복문이 끝난 뒤 마지막 배포 그룹의 개수를 `answer`에 추가한다.

### 복잡도
- 시간 복잡도 : O(n)
- 공간 복잡도 : O(n)
